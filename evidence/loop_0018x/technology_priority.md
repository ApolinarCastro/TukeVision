# Technology priority decision

1. **P0 — implement now:** internal deterministic feature extraction, config-driven signals, explainable risk aggregation, bounded retention and operational-chain integration.
2. **P1 — validate next:** real-world behavior validation with reviewed zone metadata and non-accusatory goldens.
3. **P2 — controlled future POC:** pose/action backends only after dataset, license, privacy, accuracy and rollback gates exist.
4. **Blocked:** ReID/biometrics and guilt/intent/shoplifting labels.

External execution selected: **NONE**. The baseline for this loop is the P0 deterministic implementation itself; external adapter benchmark fields are N/A by design.
